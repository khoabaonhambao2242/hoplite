# Adrian ❤ Hana — Website Bucin 💘

Single-page website bucin super interaktif dengan animasi GSAP. Pure HTML/CSS/JS — tanpa build step, langsung jalan.

## Jalankan lokal

Buka `index.html` langsung di browser, atau:

```bash
python3 -m http.server 8000
```

lalu buka http://localhost:8000

## Ganti konten

Semua teks (nama, tanggal, gombalan, alasan, surat cinta, timeline) ada di **`js/config.js`** — edit satu file itu aja.

## Deploy

Auto-deploy ke **GitHub Pages** via GitHub Actions setiap push ke `main`.
Sekali saja: aktifkan Pages di **Settings → Pages → Source: GitHub Actions**.
